나는 HTML과 CSS에 대해 얼마나 알고 있을까?

HTML이란

HTML은 HyperText Markup Language의 약자로, 웹 페이지를 만들기 위한 기본적인 마크업 언어이다.
프로그래밍 언어가 아니라 마크업 정보를 표현하는 마크업 언어로 문서의 내용 이외의 문서의 구조나 서식 등을 포함한다.

프로그래밍 언어와 마크업 언어의 차이점

범주 프로그래밍 언어 마크업 언어
목적 컴퓨터가 수행할 명령과 로직을 작성하기 위함이다. 문서의 구조와 표현 방식을 정의하기 위함이다.
기능 조건문, 반복문, 함수 등 논리적 제어가 가능하다. 텍스트나 데이터를 태그로 감싸 의미를 부여하고 문서의 레이아웃을 지정한다.
예시 Python, Java, C++, JavaScript 등이 있다. HTML, XML, Markdown 등이 있다.
실행 방식 컴파일러나 인터프리터를 통해 실행되어 동작을 수행한다. 브라우저나 뷰어가 해석하여 문서나 데이터를 표시한다.

HTML은 1991년에 팀 버너스리(Tim Berners-Lee)에 의해 개발되었다.
HTML은 웹 문서의 구조를 정의하며 텍스트, 이미지, 링크, 동영상 등 다양한 콘텐츠를 포함할 수 있다.
각 요소는 태그(tag)로 감싸서 표현하며, 브라우저는 이 태그를 해석하여 화면에 내용을 표시한다.
HTML은 CSS, JavaScript와 함께 사용되어 풍부하고 동적인 웹 페이지를 만드는데 필수적이다.

CSS란

CSS는 Cascading Style Sheets의 약자로, 웹 페이지의 스타일과 레이아웃을 정의하는 언어이다.
CSS로 HTML 요소의 색상, 글꼴, 크기, 간격 등을 지정할 수 있다.
1996년에 W3C(World Wide Web Consortium)에 의해 표준으로 제정되었다.
선택자(selector)를 사용하여 특정 HTML 요소를 선택하고, 그 요소에 스타일 규칙을 적용한다.
CSS는 HTML과 분리되어 작성할 수 있어, 유지보수와 재사용성이 뛰어나다.

CSS를 사용하는 이유

  • 웹 페이지의 디자인과 레이아웃을 쉽게 제어할 수 있다.
  • HTML과 스타일을 분리하여 코드의 가독성과 유지보수성을 높일 수 있다.
  • 한 번 작성한 CSS를 여러 페이지에서 재사용할 수 있어 효율적이다.
  • 반응형 웹 디자인을 구현하여 다양한 기기에서 최적화된 화면을 제공할 수 있다.
  • 애니메이션과 시각 효과를 통해 사용자 경험을 향상시킬 수 있다.

HTML 태그

<a> 태그의 정의 및 사용

 <a href="URL"> TEXT </a>

<a>태그는 href 특성을 통해 다른 페이지나 같은 페이지의 어느 위치, 파일, 이메일 주소와 그 외 다른 URL로 연결할 수 있는 하이퍼링크를 만든다.


특성

download

  • 링크로 이동하는 대신 사용자에게 URL을 저장할지 물어본다. 값을 저장하거나 저장하지 않을 수 있다.
    • 값이 없으면 파일 이름과 확장자는 브라우저가 다양한 인자로부터 생성해 제안한다.
  • 값을 지정하면 저장할 때의 파일 이름으로서 제안한다.
<a href="path/of/your/file" download="sample_image">다운로드</a>

적용 예시
다운로드

href

  • 하이퍼링크가 가리키는 URL이다. 링크는 HTTP 기반 URL뿐만 아니라, 브라우저가 지원하는 모든 URL 스킴을 사용할 수 있다.
    • 페이지 구획을 가리키는 프래그먼트 URL
    • 미디어 파일 일부를 가리키는 미디어 프래그먼트
    • tel: URL을 사용하는 전화번호
    • mailto: URL을 사용하는 이메일 주소

rel

  • 하나의 스페이스로 구분하는, 연결한 URL과의 관계를 나타내는 링크 유형 목록이다.

target

  • 링크한 URL을 표시할 위치. 가능한 값은 브라우징 맥락으로, 즉 탭, 창, iframe의 이름이나 특정 키워드이다.
    • _self: 기본값으로, 현재 창이나 탭에서 문서를 연다.
    • _blank: 새로운 창이나 탭에 연다.
    • _parent: 상위 프레임에서 연다.
    • _top: 현재 창 본문 전체에 링크된 문서를 연다.

<a href="https://www.google.com/">구글</a><br>
<a href="https://www.google.com/" target="_blank">새 탭에서 열기</a>

<form> 태그의 정의 및 사용

<form action="/submit" method="post">
    <label for="username">사용자 이름</label>
    <input type="text" id="username" name="username">
    <input type="submit" value="제출">
</form>

<form> 태그는 사용자로부터 데이터를 입력받고, 그 데이터를 서버로 전송할 수 있는 양식을 생성할 때 사용된다.

  • 웹에서 사용자와의 상호작용을 위한 기본적인 구조이다.

특성

accept-charset

  • 스페이스로 구분한, 서버가 허용하는 문자 인코딩의 목록이다.

action

  • 양식 데이터를 처리할 프로그램의 URI이다.

autocomplete

  • 입력 요소가 자동완성된 값을 기본값으로 가질 수 있는지 나타낸다.
    • off: 브라우저가 각 항목에 자동으로 값을 채워 넣지 않는다.
    • on: 사용자의 과거 입력값에 기반하여 브라우저가 자동으로 값을 채워 넣는다.

method

  • 양식을 제출할 때 사용할 HTTP 메서드이다.
    • post: 양식 데이터를 요청 본문으로 전송한다.
    • get: 양식 데이터를 actionURL과 ?구분자 뒤에 이어 전송한다
    • 양식이 <dialog>안에 위치할 경우 제출과 함께 대화상자를 닫는다.

target

  • 양식 제출의 결과를 표시할 위치를 나타내는 표준 키워드 혹은 사용자 지정 이름이다.

<li> 태그의 정의 및 사용

<ul> <li>Neil Armstrong</li> </ul>

<li>요소는 목록의 항목을 나타냅니다. 반드시 정렬 목록 <ol>, 비정렬 목록 <ul>, 혹은 메뉴 <menu> 안에 위치해야 합니다. 메뉴와 비정렬 목록에서는 보통 불릿으로 항목을 나타내고, 정렬 목록에서는 숫자나 문자를 사용한 오름차순 카운터로 나타냅니다.


특성

  • <li> 태그는 전역 특성만 포함한다.
  • <ol> 요소는 정렬된 목록을 나타냅니다. 보통 숫자 목록으로 표현합니다.
  • <ul> 요소는 정렬되지 않은 목록을 나타냅니다. 보통 불릿으로 표현합니다. 

<ul> 
    <li>Neil Armstrong</li>
    <li>Alan Bean</li>
    <li>Peter Canrad</li>
    <li>Edgar Mitchell</li>
    <li>Alan Shepard</li>
</ul>
적용 예시
  • Neil Armstrong
  • Alan Bean
  • Peter Conrad
  • Edgar Mitchell
  • Alan Shepard

 <h1>Important Heading</h1>

<h#> 태그는 제목(Heading)을 나타낸다.
<h1> 부터 <h6> 까지 있으며 숫자가 작을수록 더 중요한 제목을 의미하며, 문서의 구조와 계층을 표현할 때 사용된다.

  • 기본적으로 굵은 글씨이며 줄바꿈이 자동 적용된다.
  • <h1>은 가장 중요한 제목으로, 페이지 당 1 개만 사용하는 것이 좋다.
  • 문서의 논리적인 구조를 형성하며 SEO(검색 엔진 최적화)에 큰 영향을 준다.
  • 시각적으로만 큰 글씨를 만들고 싶을 경우에는 CSS 로 크기 조절하는 것이 적절하다.

    애니메이션이란

    • 오브젝트 속성의 변화를 조작하는 transition 기능의 연장선이다.
      • 변화의 시작과 끝뿐만 아니라 변화 중간의 상태도 수정 가능
      • 변화의 지속 시간, 반복 횟수, 반복 방향 등을 지정 가능

    transition vs animation

    Transition

    Animation


    @keyframes
    • 애니메이션의 프레임을 정의할 수 있다.
      • from, to : 애니메이션의 시작과 종료 상황의 스타일을 정의
      • 0% ~ 100% : 퍼센트 값으로 각 단계의 스타일 정의

    @keyframes anim_name{ from{} to{} } 
@keyframes anim_name{ 0%{} 50%{} 100%{} }

    animation
    • 애니메이션 속성을 단축하여 작성할 수 있다.
    • animation-name 과 animation-duration 은 필수, 나머지는 선택적으로 지정한다.
      • animation-name : 이름
      • animation-duration : 지속 시간
      • animation-delay : 대기 시간
      • animation-timing-function : 타이밍 함수
      • animation-iteration-count : 반복 횟수
      • animation-direction : 반복 방향
      • animation-fill-mode : 전후 상황
      • animation-play-state : 재생 상태

     animation: animation-name, animation-duration, (animation-delay), (animation-timing-function)...
